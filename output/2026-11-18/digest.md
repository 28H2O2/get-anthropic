### [Claude 平台上的关联账单](https://claude.com/resources/articles/linked-billing-on-claude-platform)

**来源**: Claude Blog

**发布日期**: 2026-11-17

**原文**: https://claude.com/resources/articles/linked-billing-on-claude-platform

**中文摘录**：

关联计费现已在 Claude 平台上推出测试版。第三方平台可以让客户在不共享 API 密钥的情况下支付 Claude API 的使用费用。今天，我们将在 Claude 平台上以测试版形式推出关联计费功能。第三方平台（如编码代理和工作流自动化工具）可以让其最终客户为 Claude API 的使用付费，而无需共享 API 密钥。最终客户保留其现有的Anthropic计费方式并自行设定支出限额，而平台则获得一种更简便、更安全的方式来提供Claude。在第三方平台上为 Claude API 的使用付费，通常意味着需要共享一个 API 密钥，该密钥的作用类似于密码：任何持有该密钥的人都可以发起由客户付费的请求，因此平台必须妥善保管该密钥。
